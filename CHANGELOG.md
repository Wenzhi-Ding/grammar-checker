# Changelog

All notable changes to this project are documented here. Version numbers follow the `version` field in `package.json`.

## [0.1.1] - 2026-08-01

### Added

- English proofreading prompt now explicitly flags pronouns whose antecedent is ambiguous or mismatched — e.g. after a disjunctive subject like "Dario or Anthropic's PR team …", a later "he is" can only refer to one of the two and must be flagged (restate the noun, or use a pronoun that covers both). Applies to both adapters, since the Gemini prompt re-exports the same English framing (`lib/providers/openai-compatible/prompt/en.ts`).

### Changed

- `AGENTS.md`: documented the four places where provider `apiKey` gating is enforced (`presets.ts`, `Polisher.tsx` ×2, `usePolish.ts`) and the rule to audit with `grep` scoped to `*.{ts,tsx}`.
- `next-env.d.ts`: regenerated by the Next.js dev server (routes types path now points at `.next/dev/types/`).
